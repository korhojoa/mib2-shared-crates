# Terms

- MIB2 is the second-generation Volkswagen Group infotainment platform.
- Android Auto and CarPlay project phone applications onto a head-unit display.
- A loader is a library that starts the configured extension modules.
- H.264 is a compressed video format. MPEG-TS groups video into transport packets.
- A display manager context identifies a display surface that an application can select.
- EGL connects graphics rendering to a window. GLES2 is the OpenGL ES 2.0 drawing interface.
- MPE identifies the native encoder events that report video encoder activity.
- PPS means Persistent Publish/Subscribe, the QNX service for shared named state objects.
- ARM identifies the processor architecture. QNX is the operating system.
- Cargo builds Rust packages. Clippy checks Rust code for common errors.
- SHA256 is a file checksum algorithm.
- An access point supplies a wireless network. Bluetooth supplies short-range device communication.
